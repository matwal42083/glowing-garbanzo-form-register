# Registration Form

A responsive registration form built as a freeCodeCamp learning project using HTML and CSS.

## Features

- Collects a user’s name, email address, and password.
- Offers personal or business account selection and terms acceptance.
- Includes profile picture upload, age, referral source, and bio fields.
- Uses native form validation for required fields and input constraints.

## Run locally

Open `index.html` in a web browser. No build tools or dependencies are required.

## Form submission

The form currently submits to freeCodeCamp’s demo registration endpoint (`https://register-demo.freecodecamp.org`). It is an educational example, not a production registration service.
